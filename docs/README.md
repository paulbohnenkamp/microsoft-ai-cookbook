# Documentation

This directory holds durable reference material for the cookbook. Recipe instructions belong in `recipes/`.

- `fictional-enterprise.md` defines the small shared setting.
- `cookbook-environment.md` defines the Northstar platform boundaries, setup sequence, and environment inventory.
- `recipe-template.md` defines the standard recipe shape.
- `specs/` holds durable repository specifications.

Cookbook-wide agent prompts are in [`../prompts/`](../prompts/). Recipe-specific prompts and artifacts belong inside the relevant recipe directory.
