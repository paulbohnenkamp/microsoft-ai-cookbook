# Cookbook foundation specification

## Purpose

Provide concise, practical recipes for application and solution engineers building Microsoft enterprise business solutions.

## Constraints

- Keep examples small and progressive.
- Teach one significant new concept per normal recipe.
- Use Northstar only as lightweight fictional continuity.
- Introduce AI only when it solves a real problem better than deterministic software.
- Do not begin with application frameworks, infrastructure-as-code, deployment pipelines, or a multi-service agent platform.

## First slice

The first slice establishes the public overview, fictional-enterprise context, recipe format, and a 10–15 recipe learning roadmap. It does not implement Recipe 001.
